# 不玩了（FocusGate）

一款本地优先的 Android 短视频自控工具。打开受控应用时，它会先覆盖目标内容，让你确认当下状态、使用目的和计划时长；时间到后再次全屏提醒，帮助你把“无意识刷视频”变成一次有边界的选择。

当前版本：`1.4.7`（`versionCode 13`）

> 这是个人开源项目，不是家长控制、企业设备管理或不可绕过的系统级封禁工具。用户可以随时关闭无障碍服务或卸载应用。

## 下载与安装

前往仓库的 [Releases](../../releases) 页面下载 APK。

GitHub Release 中的 APK 是使用 Android 默认调试证书生成的社区测试版，方便体验和更新当前测试安装；它不等同于应用商店正式签名包。Android 可能提示“未知来源”，请只从本仓库下载，并核对 Release 页面提供的 SHA-256。

首次使用：

1. 安装并打开“不玩了”。
2. 点击“开启无障碍服务”，在系统设置中找到 FocusGate 并授权。
3. 建议允许通知、后台运行/自启动，并关闭针对本应用的省电限制。
4. 打开受控应用，检查是否出现 15 秒暂停与意图确认界面。

## 主要功能

- 使用 `TYPE_ACCESSIBILITY_OVERLAY` 在受控应用上方显示全屏闸门，失败时自动采用 Activity 备用方案。
- 打开前暂停 15 秒，并记录状态、目的与计划使用时长。
- 严格按照用户确认时刻和选择时长生成一次到点提醒，不插入额外的 5 分钟或 70% 弹窗。
- 对短暂系统弹窗、通知栏切换和页面抖动做防抖，减少重复弹出与误判离开。
- 支持“再使用 5 分钟”、结束使用和返回桌面。
- 本地记录当日、近 7 天、近 30 天趋势与行为复盘，可在应用内清空。
- 服务重连与进程恢复后尽量恢复未完成会话和原定截止时间。

## 隐私与权限

当前版本没有申请联网权限，也没有广告、账号、云同步或第三方分析 SDK。状态、意图、时间和复盘记录保存在本机应用私有空间。完整说明见 [PRIVACY.md](PRIVACY.md)。

| 权限/能力 | 是否必要 | 用途 |
| --- | --- | --- |
| 无障碍服务 | 必需 | 检测受控应用的窗口切换并显示专用覆盖层 |
| 通知 | 建议 | 显示前台服务状态和备用提醒 |
| 悬浮窗 | 可选 | 少数系统拒绝无障碍覆盖层时的备用能力 |
| 忽略电池优化/自启动 | 建议 | 降低系统休眠或清理后台后服务失联的概率 |

无障碍配置明确设置 `canRetrieveWindowContent=false` 和 `canPerformGestures=false`：应用不读取页面文本/屏幕内容，也不模拟触控手势。

## 兼容性

- 最低 Android 8.0（API 26），目标 Android 16（API 36）。
- 已重点实机验证：小米 14 Pro、Android 16 / HyperOS。
- 不同厂商会额外限制无障碍服务、自启动、后台弹出和省电策略，因此其他品牌或系统升级后仍可能需要重新授权或调整后台设置。
- 目标应用更新 Activity/窗口结构后，特别是微信视频号，识别规则可能需要同步维护。

欢迎通过 Issue 提交机型、Android/系统版本、目标应用版本、复现步骤和去除个人信息后的日志。请勿上传账号、通知内容或其他敏感数据。

## 从源码构建

需要 Android Studio、Android SDK 36 和 JDK 17。

Windows：

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

Windows 上建议把仓库放在不含中文字符的路径中；当前 Gradle/JUnit 组合在部分中文路径下可能出现测试类已编译但测试进程无法加载的问题。

macOS / Linux：

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```

APK 生成于 `app/build/outputs/apk/debug/app-debug.apk`。
